# MAPGEN2

Second go map generator I did, many years ago. Both of were made them in order to learn the language, so the code is pretty embarrassing.
No idea if this even compiles these days.

**Features:**
- Clear continents and landmasses 
- Distinctive mountainranges
- River generation using djikstra-maps
- Biome/climate generation based on precipitation/moisture, temperature, altitude and distance to shore
- Rudimentary wind-map generation that influences climate
- Rendered in lovely ASCII!
